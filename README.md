# iara creates

Portfolio website of Iara Lucena, Content Designer & UX Writer in the Netherlands.

A single static page (`index.html`) with its images in `images/`. No build step.

## Updating the site
Edit `index.html` or replace files in `images/` (keep the same file names) and commit to `main`.
Cloudflare Pages publishes every commit to `main` automatically.

### Cloudflare Pages settings
- Framework preset: None
- Build command: (leave empty)
- Build output directory: `/`
