# iaracreates

Website of Iara Lucena: content design, and For the Love of Zelda, a handmade collection by iaracreates.
A static site in three languages. Every page is ready-made HTML, so hosting only has to serve the files.

| Language | Address |
|---|---|
| English | `/` |
| Português (Brasil) | `/pt-br/` |
| Nederlands | `/nl/` |

## How it's put together
- `src/app.html`: the whole site (layout, styles, behaviour and every word in all three languages). It's the same
  file as the prototype on claude.ai.
- `copy-edits.json`: copy changes saved in the prototype's copy editor. They take priority over the text in `src/app.html`.
- `src/llms.txt`: the summary for AI tools.
- `images/`, `brand/`: photos and logos.
- `build_site.py`: opens every page in a headless browser and saves it fully rendered, in all three languages.

Generated by the build (don't edit by hand): `index.html`, `404.html`, `pt-br/`, `nl/`, `content-design/`,
`handmade/`, `about/`, `contact/`, `assets/`, `sitemap.xml`, `robots.txt`, `llms.txt`, `_redirects`.

## Updating the site
1. Change copy in the prototype's copy editor (it translates to all three languages when you save), then ask
   Claude to export the edits to `copy-edits.json`. For layout or structure changes, update `src/app.html`.
2. Run `python3 build_site.py` (needs Python 3 with Playwright: `pip install playwright` then `playwright install chromium`).
3. Commit to a branch first and check Cloudflare's preview link. Merge to `main` to publish.

## Settings in `build_site.py`
- `SITE_URL`: the public address, used for search engines and social previews.
- `HIDE_HANDMADE_FROM_SEARCH`: `True` until the January 2027 switch-over. Handmade pages are online but marked
  "noindex" and left out of the sitemap, so they don't compete with the shop. Set to `False` on switch-over day and rebuild.

- `HANDMADE_SLUG`: `"fortheloveofzelda"` for now, so the Handmade section lives at `/fortheloveofzelda/…` under
  the collection's name; `/handmade/…` redirects there temporarily. At the official switch-over, set it to
  `"handmade"` and rebuild (the temporary redirects disappear; add redirects from `/fortheloveofzelda/…` if needed).

## Cloudflare Pages settings (unchanged)
- Framework preset: None
- Build command: `exit 0` (or leave empty)
- Build output directory: `/`

## Good to know
- Contact form: opens the visitor's email app with the message filled in, addressed to iaracreates.info@gmail.com.
  To receive messages without the email app, connect a form service (for example FormSubmit, as the shop uses).
- `_redirects` keeps older addresses working (`/pt/…` → `/pt-br/…`, the old AI Buddy page).
- Unknown addresses show `404.html`.
